myArray.fill(myElement, myIndex, myPosition)

The fill() method fills specified elements in an array with a value.

The fill() method overwrites the original array.

The myIndex and myPosition can be specified. (if omitted, all elements will be filled)

Demo

let myArray = ["Apple", "Banana", "Carbonara"]; // ['Apple', 'Banana', 'Carbonara']

myArray.fill("Dahlia"); // ['Dahlia', 'Dahlia', 'Dahlia']

myArray.fill("Dahlia", 1, 3); // ['Apple', 'Dahlia', 'Dahlia']

myArray.fill("Dahlia", 1, 4); // ['Apple', 'Dahlia', 'Dahlia']

myArray.join("mySeparator")

The join() method returns an array as a string.

The join() method does not change the original array.

Any separator can be specified. (the default is comma)

Demo

let myArray = ["Apple", "Banana", "Carbonara"]; // ['Apple', 'Banana', 'Carbonara']

myArray.join(); // Apple,Banana,Carbonara

myArray.join(", "); // Apple, Banana, Carbonara

myArray.join(" - "); // Apple - Banana - Carbonara

myArray.pop()

The pop() method removes the last element of an array.

The pop() method changes the original array.

The pop() method returns the removed element.

Demo

let myArray = ["Apple", "Banana", "Carbonara"]; // ['Apple', 'Banana', 'Carbonara']

myArray.pop(); // Carbonara

console.log(myArray); // ['Apple', 'Banana']

myArray.push(myElement1, myElement2, ..., myElementn)

The push() method adds new items to the end of an array.

The push() method changes the length of the array.

The push() method returns the new length.

Demo

let myArray = ["Apple", "Banana", "Carbonara"]; // ['Apple', 'Banana', 'Carbonara']

myArray.push("Dahlia"); // 4

console.log(myArray); // ['Apple', 'Banana', 'Carbonara', 'Dahlia']

myArray.reverse()

The reverse() method reverses the order of the elements in an array.

The reverse() method overwrites the original array.

Demo

let myArray = ["Apple", "Banana", "Carbonara"]; // ['Apple', 'Banana', 'Carbonara']

myArray.reverse(); // ['Carbonara', 'Banana', 'Apple']

console.log(myArray); // ['Carbonara', 'Banana', 'Apple']

myArray.shift()

The shift() method removes the first item of an array.

The shift() method changes the original array.

The shift() method returns the shifted element.

Demo

let myArray = ["Apple", "Banana", "Carbonara"]; // ['Apple', 'Banana', 'Carbonara']

myArray.shift(); // Apple

console.log(myArray); // ['Banana', 'Carbonara']

myArray.toReversed()

The toReversed() method reverses the order of the elements in an array.

The toReversed() method returns a new array.

The toReversed() method does not overwrites the original array.

The toReversed() method is the copying version of the reverse() method

Demo

let myArray = ["Apple", "Banana", "Carbonara"]; // ['Apple', 'Banana', 'Carbonara']

myArray.toReversed(); // ['Carbonara', 'Banana', 'Apple']

console.log(myArray); // ['Apple', 'Banana', 'Carbonara']

myArray.unshift(myElement1, myElement2, ..., myElementn)

The unshift() method adds new elements to the beginning of an array.

The unshift() method overwrites the original array.

Demo

let myArray = ["Apple", "Banana", "Carbonara"]; // ['Apple', 'Banana', 'Carbonara']

myArray.unshift("Dahlia"); // 4

console.log(myArray); // ['Dahlia', 'Apple', 'Banana', 'Carbonara']

myArray.with(myIndex, myElement)

The with() method updates a specified array element.

The with() method returns a new array.

The with() method does not change the original array.

Demo

let myArray = ["Apple", "Banana", "Carbonara"]; // ['Apple', 'Banana', 'Carbonara']

myArray.with(2, "Dahlia"); // ['Apple', 'Banana', 'Dahlia']

console.log(myArray); // ['Apple', 'Banana', 'Carbonara']
