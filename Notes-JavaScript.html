constructor Property

The constructor property returns the function that created the specific data type prototype.

Demo for Datatype Number

let myNumber = 100;
myNumber.constructor; // [Function: Number]

Demo for Datatype String

let myString = "Hello";
myString.constructor; // [Function: String]

Demo for Datatype Boolean

let myBoolean = true;
myBoolean.constructor; // [Function: Boolean]

Demo for Datatype Array

let myArray = [30, "Hi", false];
myArray.constructor; // [Function: Array]

Demo for Datatype Object

let myObject = { name: "John", age: 25, availability: true };
myObject.constructor; // [Function: Object]

Demo for null & undefined

let myVariable1 = null;
myVariable1.constructor; // TypeError: Cannot read properties of null (reading 'constructor')

let myVariable2 = undefined;
myVariable2.constructor; // TypeError: Cannot read properties of undefined (reading 'constructor')

EPSILON Property

The EPSILON returns the difference between the smallest floating point number greater than 1 and 1.

If myVariable.EPSILON is written, it will return undefined.

Therefore, need to write exactly like Number.EPSILON, which has the value of 2.220446049250313e-16.

Demo

let myVariable = 100;
myVariable.EPSILON; // undefined

Number.EPSILON; // 2.220446049250313e-16

isFinite() Method

The isFinite() method returns true if a value is a finite number.

The isFinite() method converts the value to a number before testing it.

Otherwise it returns false.


The Number.isFinite() method returns true if a number is a finite number.

If the data type is not in number data type, it returns false.

Demo

let myNumber1 = 100; // number
isFinite(myNumber1); // true
Number.isFinite(myNumber1); // true

let myNumber2 = "100"; // string
isFinite(myNumber2); // true
Number.isFinite(myNumber2); // false

let myNumber3 = Infinity; // number
isFinite(myNumber3); // false
Number.isFinite(myNumber3); // false

let myNumber4 = true; // boolean
isFinite(myNumber4); // true
Number.isFinite(myNumber4); // false

isInteger() Method

The Number.isInteger() method returns true if a value is an integer of the datatype Number.

Otherwise it returns false.

Demo

Number.isInteger(150); // true
Number.isInteger(45.34); // false

isNaN() Method

The isNaN() method returns true if a value is NaN.

The isNaN() method converts the value to a number before testing it.

Otherwise, it will returns false.


The Number.isNaN() method returns true if the number is NaN.

Returns false if the datatype is not in number.

Demo

let myNumber1 = NaN; // number
isNaN(myNumber1); // true
Number.isNaN(myNumber1); // true

let myNumber2 = 50; // number
isNaN(myNumber2); // false
Number.isNaN(myNumber2); // false

let myString = "NaN"; // string
isNaN(myString); // true
Number.isNaN(myString); // false

isSafeInteger() Method

The Number.isSafeInteger() method returns true if a number is a safe integer.

Otherwise it returns false.

Demo

Number.isSafeInteger(100); // true
Number.isSafeInteger(4.5); // false

MAX_SAFE_INTEGER Property

The Number.MAX_SAFE_INTEGER represents the maximum safe integer.

Number.MAX_SAFE_INTEGER = (253-1).

Demo

let myNumber = 100;
myNumber.MAX_SAFE_INTEGER; // undefined

Number.MAX_SAFE_INTEGER; // 9007199254740991

MIN_SAFE_INTEGER Property

The Number.MIN_SAFE_INTEGER represents the minimum safe integer.

Number.MIN_SAFE_INTEGER = -(253-1).

Demo

let myNumber = 100;
myNumber.MIN_SAFE_INTEGER; // undefined

Number.MIN_SAFE_INTEGER; // -9007199254740991

MAX_VALUE Property

The Number.MAX_VALUE returns the largest number possible.

Number.MAX_VALUE = 1.7976931348623157e+308.

Demo

let myNumber = 100;
myNumber.MAX_VALUE; // undefined

Number.MAX_VALUE; // 1.7976931348623157e+308

The Number.MIN_VALUE returns the smallest number possible.

Number.MIN_VALUE = 5e-324.

Demo

let myNumber = 100;
myNumber.MIN_VALUE; // undefined

Number.MIN_VALUE; // 5e-324

parseFloat() Method

The Number.parseFloat() method parses a value as a string and returns the first number.

Only the first number found is returned.

If the first character cannot be converted, NaN is returned.

Leading and trailing spaces are ignored.

Demo

let myNumber = 10; // number
Number.parseFloat(myNumber); // 10 (number)

let myString1 = "10"; // string
Number.parseFloat(myString1); // 10 (number)

let myString2 = "10 20 30"; // string
Number.parseFloat(myString2); // 10 (number)

let myString3 = " 55 "; // string
Number.parseFloat(myString3); // 55 (number)

let myString4 = "40H"; // string
Number.parseFloat(myString4); // 40 (number)

let myString5 = "H40"; // string
Number.parseFloat(myString5); // NaN (number)

let myBoolean = true; // boolean
Number.parseFloat(myBoolean); // NaN (number)
